# TLS File Transfer
A TLS-secured file transfer client and server in Java.

## Project 🌳
```
.
├── Makefile
└── src
    ├── MyTLSFileClient.java
    └── MyTLSFileServer.java
```

### Usage
Build and run using the Makefile:
```bash
make
java MyTLSFileServer
java MyTLSFileClient
```

## Commands
1. To build the project use `make`.
2. To start the server use `java MyTLSFileServer`.
3. To start the client use `java MyTLSFileClient`.
